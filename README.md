# E-Raport Pendamping

A school report-card / student-progress application.

| Path       | Stack                                | Role                                    |
| ---------- | ------------------------------------ | --------------------------------------- |
| `api/`     | Laravel 12 (PHP 8.2+) + Sanctum      | REST API, auth, PDF report generation   |
| `frontend/`| React 19 + Vite + Tailwind CSS v4    | SPA (admin + teacher dashboards)        |
